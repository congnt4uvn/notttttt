### Part 1 — Understanding LLMs

### 3\. What is an LLM?

LLM stands for Large Language Model.

An LLM is an artificial intelligence model trained on large amounts of text and other data to understand and generate language.

Examples:

* GPT

* Claude

* Gemini

* Llama

* Qwen

### 3.1 How does an LLM work?

At a simplified level:

* Receive input text.

* Convert text into tokens.

* Convert tokens into numerical representations.

* Process them through a Transformer neural network.

* Predict the next token.

* Repeat token generation until the response is complete.

Example:

User input:

```text
What is LangChain?
```

Simplified token prediction:

```text
LangChain
    ↓
is
    ↓
a
    ↓
framework
    ↓
for
    ↓
building
    ↓
LLM
    ↓
applications.
```

The actual model predicts probability distributions over possible next tokens, rather than selecting words through a fixed dictionary.

### 3.2 Important LLM concepts

| Concept        | Explanation                                     |
| -------------- | ----------------------------------------------- |
| Token          | A unit of text processed by the model           |
| Tokenization   | Converting text into tokens                     |
| Embedding      | Numerical vector representation                 |
| Context Window | Maximum input context a model can process       |
| Temperature    | Controls randomness in generation               |
| Inference      | Using a trained model to generate predictions   |
| Training       | Updating model parameters using data            |
| Fine-tuning    | Further training an existing model              |
| Hallucination  | Generating incorrect or unsupported information |

### 3.3 What is a Transformer?

Most modern LLMs are based on the Transformer architecture.

![ILLUSTRATION DU TRANSFORMER - Loïck BOURDOIS](https://images.openai.com/static-rsc-4/CvlhAfYa9x3YrbRmVzlY0NosdPwFgpjj65YfgSUarHptdMbd7aIN2pEOX3Rn_bhQ0HcjW4wpg1ohkb95umtoJ2NtQ3LjCdtf33woq9_3VFAZCxtvGXRI62jGhrmVaEJvMfEJVL6twJ20dynBZ4oQ048pBMTOmeG8GxP4XKOcNQiXEsSr06C0WDuzO0YYDVUu?purpose=fullsize)

Important components:

* Input embeddings

* Positional information

* Self-attention

* Multi-head attention

* Feed-forward neural networks

* Residual connections

* Layer normalization

For today, remember:

Self-attention allows a model to identify relationships between different tokens in a sequence.

For example:

```text
The developer created an application.
He deployed it yesterday.
```

The model uses contextual information to understand that "He" refers to "the developer".

You will study Transformer architecture in more depth when learning advanced LLM application development.

### 4\. LLM application vs traditional application

Consider a traditional Python application.

```python
def calculate_total(price, quantity):
    return price * quantity

print(calculate_total(100, 5))
```

The result is deterministic:

```text
500
```

Now consider an LLM application.

```python
question = "Explain why developers use LangChain."
```

The model generates a natural-language answer based on its learned patterns and provided context.

| Traditional application | LLM application             |
| ----------------------- | --------------------------- |
| Rule-based logic        | Model-based generation      |
| Predictable output      | Potentially variable output |
| Explicit algorithms     | Learned model behavior      |
| Structured inputs       | Natural-language inputs     |
| Usually deterministic   | Often probabilistic         |

Real-world AI applications combine both approaches.

For example, an AI banking assistant might use an LLM to understand a question but Python functions and database queries to retrieve accurate account information.

### 5.2 Why do we need LangChain?

Imagine building an application with:

* 1 LLM

* 5 tools

* 1 vector database

* 10 prompt templates

* Multiple workflows

* Conversation memory

Without a framework, you must manage all these integrations and execution flows yourself.

LangChain provides reusable abstractions and integrations to simplify this work.

LangGraph provides explicit workflow orchestration when the application needs stateful, multi-step execution.

### Part 3 — LangChain vs LangGraph

### 6\. What is LangChain?

LangChain is an open-source framework for building applications powered by language models.

Its main capabilities include:

* Model integrations

* Prompt templates

* Structured outputs

* Tools

* Agents

* Retrieval-Augmented Generation (RAG)

* Middleware

Example architecture:

User Input

Prompt Template

Chat Model

Generated Answer

Example use case:

```text
User: Translate "Good morning" into Vietnamese.

LangChain:
    1. Receive input.
    2. Create translation prompt.
    3. Send prompt to model.
    4. Return translation.

Output: Chào buổi sáng.
```

### 7\. What is LangGraph?

LangGraph is a framework for building stateful, long-running agent workflows.

Instead of only connecting components sequentially, you define a graph consisting of:

* State

* Nodes

* Edges

* Conditional edges

* Execution logic

Example:

START

Analyze User Request

Decision Node

Path A

Search Tool

Path B

Direct LLM

Generate Answer

END

### 8\. Comparison

| Feature               | LangChain                       | LangGraph                    |
| --------------------- | ------------------------------- | ---------------------------- |
| Main purpose          | LLM application development     | Workflow orchestration       |
| Model integration     | Yes                             | Yes                          |
| Prompt templates      | Yes                             | Can use LangChain components |
| Tools                 | Yes                             | Yes                          |
| State management      | Component/application dependent | Core capability              |
| Conditional workflows | Agents and runnable composition | Graph edges                  |
| Persistence           | Integration dependent           | Built-in checkpointing model |
| Human approval        | Via integrations/agents         | Interrupts and resume        |
| Multi-agent systems   | Supported                       | Strong orchestration support |

Important: LangGraph does not replace LangChain. They complement each other, and LangGraph can also be used without LangChain.

There are two concepts you should distinguish:

* Model: The actual trained neural network.

### 10\. Understand the API request

Before using LangChain, understand how to communicate with a model directly.

The basic request flow:

```text
Python Application
       |
       v
   API Request
       |
       v
  Authentication
       |
       v
   LLM Provider
       |
       v
   Model Inference
       |
       v
   API Response
       |
       v
  Python Application
```

Example request structure:

```python
messages = [
    {
        "role": "system",
        "content": "You are a helpful Python teacher."
    },
    {
        "role": "user",
        "content": "Explain Python decorators."
    }
]
```

The `system` message provides instructions, while the `user` message contains the user's request.

The model returns an assistant response.

### 11\. What is an API Key?

An API key is a credential used to authenticate your application with an API provider.

You will work with two environment variables:

```env
OPENAI_API_KEY=your_openai_api_key
HF_TOKEN=your_huggingface_token
```

Get your credentials here:

* OpenAI: [Create API key](https://platform.openai.com/api-keys?utm_source=chatgpt.com)

* Hugging Face: [Create access token](https://huggingface.co/settings/tokens?utm_source=chatgpt.com)

For Hugging Face Inference Providers, create a fine-grained token with permission to make inference calls.

Security rules:

* Never hardcode API keys in Python source code.

* Never commit `.env` to GitHub.

* Never expose API keys in frontend JavaScript.

* Use separate credentials for development and production.

* Monitor API usage and costs.

### 13\. First application: Connect to OpenAI

Create `main.py`:

```python
import os

from dotenv import load_dotenv
from langchain.chat_models import init_chat_model

load_dotenv()

# Initialize OpenAI model
model = init_chat_model(
    "openai:gpt-5.5",
    temperature=0
)

# Send a prompt
response = model.invoke(
    "Explain what LangChain is in simple terms."
)

# Print the response
print(response.content)
```

Run:

```bash
python main.py
```

Expected output (illustrative):

```text
LangChain is a framework for building
applications powered by large language models.

It provides components for connecting models,
creating prompts, integrating tools, and
building AI agents.
```

The actual answer will vary.

Understand the code:

`load_dotenv()`

Loads configuration from the `.env` file.

`init_chat_model()`

Creates a chat model using the specified provider and model identifier.

`temperature=0`

Reduces randomness in generation.

`model.invoke()`

Sends a request to the model and waits for the result.

`response.content`

Extracts the generated text from the response object.

The unified `init_chat_model()` interface is useful because it supports multiple providers through their respective integration packages. LangChain Reference

### 14\. Second application: Connect to Hugging Face

Now let's use an open-weight model through Hugging Face Inference Providers.

For this example, we will use:

`openai/gpt-oss-120b:fastest`

This is an open-weight model served through the Hugging Face Inference Providers ecosystem. It is not an OpenAI-hosted GPT model.

Create `main_hf.py`:

```python
import os

from langchain_openai import ChatOpenAI

    "Explain what LangGraph is in simple terms."
)

print(response.content)
```

### 15\. Build a reusable LLM Factory

Now let's combine both integrations into one application.

This is an important software engineering pattern: Factory Pattern.

Instead of creating different applications for different providers, we create one factory that returns the requested model.

Create `app/llm_factory.py`:

```python
import os

from langchain.chat_models import init_chat_model
from langchain_openai import ChatOpenAI

def create_llm(provider: str):
    """
    Create an LLM based on the selected provider.

    Supported providers:
        - openai
        - huggingface
    """

    provider = provider.lower()

    if provider == "openai":

        return init_chat_model(
            "openai:gpt-5.5",
            temperature=0
        )

    elif provider == "huggingface":

        hf_token = os.getenv("HF_TOKEN")

        if not hf_token:
            raise ValueError("HF_TOKEN is missing!")

        return ChatOpenAI(
            model="openai/gpt-oss-120b:fastest",
            base_url="https://router.huggingface.co/v1",
            api_key=hf_token,
            temperature=0
        )

    else:
        raise ValueError(
            f"Unsupported provider: {provider}"
        )
```

Create `main.py`:

```python
import os

from dotenv import load_dotenv
from app.llm_factory import create_llm

load_dotenv()

provider = os.getenv("PROVIDER", "openai")

model = create_llm(provider)

question = "What is the difference between LangChain and LangGraph?"

response = model.invoke(question)

print("Provider:", provider)
print("Question:", question)
print("Answer:", response.content)
```

Now change `.env`:

```env
PROVIDER=openai
```

Or:

```env
PROVIDER=huggingface
```

You can switch providers without changing `main.py`.

### Exercise 3 — Python coding

Create a program that:

* Reads a question from the user.

* Sends it to an LLM.

* Prints the response.

* Continues until the user types `exit`.

Try solving it yourself first.

```python

import os
from dotenv import load_dotenv

from app.llm_factory import create_llm

load_dotenv()

provider = os.getenv("PROVIDER", "openai")

model = create_llm(provider)

print(f"Connected to: {provider}")
print("AI Chatbot started. Type 'exit' to quit.")

while True:

    question = input("\nYou: ").strip()

    if question.lower() == "exit":
        print("Goodbye!")
        break

    if not question:
        continue

    try:
        response = model.invoke(question)
        print("\nAI:", response.content)

    except Exception as error:
        print("Error:", error)
```
