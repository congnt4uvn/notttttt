### 1\. Tổng quan lộ trình Java

Java Developer Roadmap

6 tháng

* Phase 1 – Java Fundamentals

    Tuần 1–3 · Cú pháp, kiểu dữ liệu, OOP, Collections, Exception.

* Phase 2 – Advanced Java

    Tuần 4–6 · Generics, Stream API, Lambda, Multithreading, JVM.

* Phase 3 – Database & SQL

    Tuần 7–8 · MySQL, PostgreSQL, JDBC, JPA, Hibernate.

* Phase 4 – Spring Ecosystem

    Tuần 9–14 · Spring Core, Spring Boot, REST API, Security.

* Phase 5 – Backend Engineering

    Tuần 15–19 · Testing, Redis, Kafka, Docker, Microservices.

* Phase 6 – Advanced & Deployment

    Tuần 20–24 · AWS, CI/CD, System Design, Performance.
