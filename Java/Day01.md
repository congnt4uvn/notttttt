### PART 2 – JDK, JRE, JVM (20 minutes)

Đây là kiến thức nền tảng rất quan trọng. Bạn cần hiểu rõ trước khi viết Java.

### 5\. What is JVM?

JVM – Java Virtual Machine

JVM là máy ảo Java, chịu trách nhiệm thực thi Java bytecode.

Java source code không trực tiếp chạy trên CPU. Nó được biên dịch thành bytecode trước, sau đó JVM thực thi bytecode này.

![Dive Into Systems](https://images.openai.com/static-rsc-4/qrEaifydbYjsK5ScbhiF2YM2wWakfIL-ZUOFWIU5RkOktM2hSOaNlmbvHsRrHDI2ce3tZzSp9BrmL4hFN9LSlcWco5TmzSi1lQc8TBbyYLPbne96LpiS12KSeFEbDSZKApPpZOs24lmhTzmJGdgpSEzhJOQ6DviDA5M-YDwXARogJp7T01qyGakNHPPF_HQN?purpose=fullsize)

Example:

```text
Main.java
    |
    v
Java Compiler (javac)
    |
    v
Main.class (Bytecode)
    |
    v
JVM
    |
    v
Operating System / CPU
```

Explanation:

* `.java`: Java source code.

* `javac`: Java compiler.

* `.class`: Compiled bytecode.

* `JVM`: Executes bytecode.

### 6\. What is JRE?

JRE – Java Runtime Environment

JRE cung cấp môi trường cần thiết để chạy ứng dụng Java.

It contains the JVM and supporting runtime libraries.

Ví dụ: Bạn chỉ muốn chạy một ứng dụng Java đã được biên dịch, bạn cần môi trường runtime tương ứng.

### 7\. What is JDK?

JDK – Java Development Kit

JDK là bộ công cụ dành cho nhà phát triển Java.

It includes tools to develop, compile, debug and run Java applications.

Một số công cụ quan trọng:

| Tool    | Purpose                   |
| ------- | ------------------------- |
| java    | Run Java applications     |
| javac   | Compile Java source code  |
| jshell  | Interactive Java shell    |
| javadoc | Generate documentation    |
| jar     | Package Java applications |

### Relationship between JDK, JRE and JVM

![Understanding the Java Ecosystem: JVM - JRE - JDK | by Syed Fawzul Azim | Medium](https://images.openai.com/static-rsc-4/mUohoQMTRMxQK2JdVkrgpdeTSmmwSxSiseHidISSOLXRSHCbVCHWobvREvHAhB_fkOwRkUwfpunO66vrj6Fg3KIaetqusSKolh5i-Bdui7OmKM7qt5ROrxsXfBdavkQLyBfrCTep_K-8nnaGoeyZB1rS8W2sg40VeRBdBJnhvCBMq81CMHG9ucpa-a-PaTUK?purpose=fullsize)

Cách nhớ:

* JVM = Execute bytecode.

* JRE = JVM + Runtime libraries.

* JDK = Development tools + Runtime components.

Lưu ý: Trong các phiên bản Java hiện đại, JRE không còn được phân phối như một bộ cài độc lập theo cách truyền thống. Khi học và phát triển, bạn nên cài JDK.

### 8\. Why is Java platform independent?

Java follows the principle:

Write Once, Run Anywhere (WORA).

Ví dụ:

Bạn viết code trên Windows:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

Compiler tạo ra:

```text
Main.class
```

File bytecode này có thể chạy trên các hệ điều hành khác nhau nếu có JVM tương thích.

Java Bytecode (.class)

Windows

JVM

Linux

JVM

JVM

Same bytecode, compatible JVM implementations

### PART 4 – Java Syntax Fundamentals (20 minutes)

### 10\. Basic Java program structure

Look at this program:

```java
public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }

}
```

Output:

```text
Hello World
```

Let's understand every part.

### 10.1 `public class Main`

```java
public class Main {
}
```

English: A class is a blueprint for creating objects.

Vietnamese: Class là khuôn mẫu dùng để tạo ra các đối tượng (Objects).

Explanation:

* `public`: Access modifier.

* `class`: Keyword used to declare a class.

* `Main`: Class name.

* `{ }`: Defines the class body.

Rule: If a class is declared `public`, the source filename must match the class name.

For example:

```text
Main.java
```

### 10.2 `public static void main(String[] args)`

```java
public static void main(String[] args) {

}
```

This is the main method – điểm bắt đầu thực thi của một chương trình Java thông thường.

| Keyword  | Meaning                                  |
| -------- | ---------------------------------------- |
| public   | Accessible by the JVM launcher           |
| static   | Can be called without creating an object |
| void     | Does not return a value                  |
| main     | Entry-point method name                  |
| String[] | Array of strings                         |
| args     | Command-line arguments                   |

For now, remember this structure:

```java
public static void main(String[] args) {
    // Your Java code
}
```

We will study `static`, arrays and methods in detail in later lessons.

### 10.3 `System.out.println()`

This command displays information on the console.

```java
System.out.println("Hello Java");
System.out.println("I am learning Java");
System.out.println(100);
```

Output:

```text
Hello Java
I am learning Java
100
```

There are three common output methods:

| Method    | Behavior                       |
| --------- | ------------------------------ |
| print()   | Prints without a new line      |
| println() | Prints and moves to a new line |
| printf()  | Prints formatted output        |

Example:

```java
System.out.print("Hello ");
System.out.print("Java");
```

Output:

```text
Hello Java
```

Example with `println()`:

```java
System.out.println("Hello");
System.out.println("Java");
```

Output:

```text
Hello
Java
```

Example with `printf()`:

```java
String name = "Alex";
int age = 25;

System.out.printf("My name is %s and I am %d years old.", name, age);
```

Output:

```text
My name is Alex and I am 25 years old.
```

Formatting symbols:

| Symbol | Data           |
| ------ | -------------- |
| %s     | String         |
| %d     | Integer        |
| %f     | Floating-point |
| %n     | New line       |

### 10.4 Comments in Java

Comments are used to explain code. The compiler ignores comments.

Single-line comment:

```java
// This is a single-line comment

System.out.println("Hello Java");
```

Multi-line comment:

```java
/*
    This is a multi-line comment.
    We can write several lines here.
*/

System.out.println("Hello Java");
```

Documentation comment:

```java
/**
 * This method displays a greeting.
 */
```

### 10.5 Java is case-sensitive

Java distinguishes uppercase and lowercase letters.

```java
int age = 25;
int Age = 30;
```

These are two different variables.

Incorrect:

```java
system.out.println("Hello");
```

Correct:

```java
System.out.println("Hello");
```

Remember: `System` starts with an uppercase `S`.

### 14\. Compile and run Java manually

Ngoài IntelliJ IDEA, bạn cũng nên biết cách chạy Java thông qua Terminal.

Step 1 – Compile:

```bash
javac Main.java
```

This generates:

```text
Main.class
```

Step 2 – Execute:

```bash
java Main
```

Output:

```text
Hello World!
```

Important difference:

```bash
javac Main.java
```

Compiles source code.

```bash
java Main
```

Runs the compiled Java class.

Không viết `java Main.class` khi chạy theo cách thông thường.
